WaveMixings.esa — Method
esa(probe::AbstractMatrix{T}, Τ::T, self::WaveMixing) where {T <: Real}

Calculates the signal from energies and oscillator strengths as input. The inputs must be 2D Array, i.e. Matrix. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Excited State Absorption Dynamics.

Arguments

  • probe: probe pulse energies.
  • WaveMixing: composite containing oscillators, method and energies parameters.
  • Τ: pulse length.

Returns

Calculates window and updates the WaveMixing composite (ESA) with it. (Matrix with n-probe columns, one column has all sums for one probe pulse energy).

Description

This function estimates the Window (window) parameter under the following approximations:

  • Evolutions of electronic coherences in the DW operators are evaluated within the short-time classical Condon approximation.
  • T-evolutions of electronic populations, are replaced by evolutions along trajectories.
  • The quantum thermal distribution in the electronic ground state is substituted by the corresponding phase-space Wigner distribution.
  • The trace over vibrational degrees of freedom is replaced by stochastic sampling of the initial conditions.

The corresponding Window formula (see Ref. [1] formula 60) of the excited-state absorption (ESA) reads:

\[W_{II}^{int}(\omega_{pr},\boldsymbol{R}_{e},\boldsymbol{P}_{e}) = \sum_{f}^{ } E_{pr}^{2}(\omega_{pr}-U_{fe(T)}(\boldsymbol{R}_{e})) \left| (\boldsymbol{\mu}_{e(T)t}(\boldsymbol{R}_{e}) \right|^{2} \]

Cite

[1] Gelin et.al. J.Chem.TheoryComput.2021, 17, 2394−2408

See also se, and se_strong.

WaveMixings.esa_dispersion — Method
esa_dispersion(probe::T, dispersion::AbstractMatrix{T}, Τ::T,
               self::WaveMixing, dephase::T=0.01) where {T <: Real}

Calculates the dispersed signal (eq. 64 in Gelin JCTC, 2394. 2021) from energies and oscillator strengths as input. The inputs must be 2D Array, i.e. Matrix. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Excited State Absorption Dynamics.

Arguments

  • probe: a probe pulse energy.
  • dispersion: array of dispersion energies.
  • Τ: pulse length.
  • WaveMixing: composite containing oscillators, method and energies parameters.
  • dephase: dephasing parameter. the default gives 66 fs.

Returns

Calculates dispersed window and updates the WaveMixing composite (ESA) with it. (Matrix with n-probe columns, one column has all sums for one probe pulse energy).

Description

This function estimates the dispersed Window (window) transient-absorption pump-probe signal, which derives from performing the Fourier transform to the integral pump-probe signal (see esa) with respect to $\tau_{t}$. The dispersed pump-probe signal is sensitive to electronic dephasing ($\lambda$), a parameter of this function.

The corresponding dispersed Window formula (see Ref. [1] formula 64) of the excited-state absorption (ESA) reads:

\[W_{\mathrm{II}}^{dis}(\omega_{pr},\omega,\boldsymbol{R}_{e}(T),\boldsymbol{P}_{e}(T)) = E_{pr}^{2}(\omega-\omega_{pr}) \sum_{f}\frac{\nu}{\nu^{2}+(\omega-\omega_{fe(T)}(\boldsymbol{R}_{e}(T)))^{2}} |\mu_{e(T)f}(\boldsymbol{R}_{e}(T))|^{2}\]

Cite

[1] Gelin et.al. J.Chem.TheoryComput.2021, 17, 2394−2408

See also gsb_dispersion and se_dispersion.

Calculates the signal from energies and oscillator strengths as input. The inputs must be 1D Array, i.e. vectors. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Ground State Dynamics.

Arguments

  • Τ: pulse length.

Description

This function estimates the Doorway (door) parameter under the following approximations:

  • Evolutions of electronic coherences in the DW operators are evaluated within the short-time classical Condon approximation.
  • T-evolutions of electronic populations, are replaced by evolutions along trajectories.
  • The quantum thermal distribution in the electronic ground state is substituted by the corresponding phase-space Wigner distribution.
  • The trace over vibrational degrees of freedom is replaced by stochastic sampling of the initial conditions.

Calculates the Δ strong field signal from energies, oscillator strengths, and the pump laser amplitude as input. The inputs must be 1D Array, i.e. vectors. The signal is calculated merely from the dipole moments. Use with Excited State Dynamics.

Arguments

  • WaveMixing: composite containing the λ parameter. λ is the pump laser amplitude.
  • frame: frame number in the non-adiabatic trajectory. The default gives 1.

Returns

Strong field SE delta_door, single value.

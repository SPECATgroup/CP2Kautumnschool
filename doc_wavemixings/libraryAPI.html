GSB Signal

WaveMixings.gsb — Function
gsb(pump::T, Τ::T, self::WaveMixing, frame::Integer=1)  where {T <: Real}

Calculates the signal from energies and oscillator strengths as input. The inputs must be 1D Array, i.e. vectors. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Ground State Dynamics.

Arguments

  • pump: pump pulse energy.
  • Τ: pulse length.
  • WaveMixing: composite containing the method parameter. method by default is Gaussian (:gaus). Lorentzian (:lore), chirp (:chir), hyperbolic secant (:sech), and asymmetric hyperbolic secant (:assh) are available.
  • frame: frame number in the non-adiabatic trajectory. The default gives 1.

Returns

GSB door, single value.

Description

This function estimates the Doorway (door) parameter under the following approximations:

  • Evolutions of electronic coherences in the DW operators are evaluated within the short-time classical Condon approximation.
  • T-evolutions of electronic populations, are replaced by evolutions along trajectories.
  • The quantum thermal distribution in the electronic ground state is substituted by the corresponding phase-space Wigner distribution.
  • The trace over vibrational degrees of freedom is replaced by stochastic sampling of the initial conditions.

The corresponding Doorway formula (see Ref. [1] formula 56) of the ground state bleach (GSB) reads:

\[D_{0}(\omega_{pu},\boldsymbol{R}_{g},\boldsymbol{P}_{g}) = \sum_{e}^{ } E_{pu}^{2}(\omega_{pu}-U_{eg}(\boldsymbol{R}_{g})) \left| (\boldsymbol{\mu}_{ge}(\boldsymbol{R}_{g}) \right|^{2} \rho_{g}^{\textrm{Wig}}(\boldsymbol{R}_{g},\boldsymbol{P}_{g})\]

Cite

[1] Gelin et.al. J.Chem.TheoryComput.2021, 17, 2394−2408

See also gsb, and gsb_strong.

WaveMixings.gsb_dispersion — Function
gsb_dispersion(probe::T, dispersion::AbstractMatrix{T}, Τ::T,
               self::WaveMixing, dephase::T=0.01) where {T <: Real}

Calculates the dispersed signal (eq. 62 in Gelin JCTC, 2394. 2021) from energies and oscillator strengths as input. The inputs must be 2D Array, i.e. Matrix. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Ground State Dynamics.

Arguments

  • probe: a probe pulse energy.
  • dispersion: array of dispersion energies.
  • Τ: pulse length.
  • WaveMixing: composite containing oscillators, method and energies parameters.
  • dephase: dephasing parameter. the default gives 66 fs.

Returns

Calculates dispersed window and updates the WaveMixing composite (GS) with it. (Matrix with n-probe columns, one column has all sums for one probe pulse energy).

Description

This function estimates the dispersed Window (window) transient-absorption pump-probe signal, which derives from performing the Fourier transform to the integral pump-probe signal (see gsb) with respect to $\tau_{t}$. The dispersed pump-probe signal is sensitive to electronic dephasing ($\lambda$), a parameter of this function.

The corresponding dispersed Window formula (see Ref. [1] formula 62) of the ground state bleach (GSB) reads:

\[W_{0}^{dis}(\omega_{pr},\omega,\boldsymbol{R}_{g}(T),\boldsymbol{P}_{g}(T)) = E_{pr}^{2}(\omega-\omega_{pr}) \sum_{e}\frac{\nu}{\nu^{2}+(\omega-\omega_{eg}(\boldsymbol{R}_{g}(T)))^{2}} |\mu_{ge}(\boldsymbol{R}_{g}(T))|^{2}\]

Cite

[1] Gelin et.al. J.Chem. Theory Comput.2021, 17, 2394−2408

See also se_dispersion and esa_dispersion.

  • Τ: pulse length.
  • WaveMixing: composite containing the λ parameter. λ is the pump laser amplitude.

Strong field GSB door, single value.

Description

This function estimates the strong field (door) parameter under the approximations of the Doorway-Window representation. The corresponding formula (see Ref. [1] formula XX) of the ground state bleach (GSB) reads:

\[ D_{0,\alpha}^{strong}(\omega_{\tau},\boldsymbol{R}_{g},\boldsymbol{P}_{g}) = \sum_{e'}\frac{ \lambda_{\textrm{pu}}^{2} \left| \mu_{\textrm{ge}}(\boldsymbol{R}_{\textrm{g}})\right|^{2}}{ \Omega_{\textrm{eg}}^{2} (\boldsymbol{R}_{g})} \left(1 - \cos\left(\Omega_{\textrm{eg}} \left(\boldsymbol{R}_{g}\right) \tau_{\textrm{pu}}\right) \right) \rho_{\textrm{g}}^{\textrm{Wig}} (\boldsymbol{R}_{g},\boldsymbol{P}_{g})\]

Cite

[1] Hefen et.al. XX 2025, XX

See also Δgsb_strong, Δse_strong, se_strong, and esa_strong.

The dispersed pump-probe signal is sensitive to electronic dephasing ($\lambda$), a parameter of this function.

The corresponding dispersed Window formula (see Ref. [1] formula 64) of the excited-state absorption (ESA) reads:

\[W_{\mathrm{II}}^{dis}(\omega_{pr},\omega,\boldsymbol{R}_{e}(T),\boldsymbol{P}_{e}(T)) = E_{pr}^{2}(\omega-\omega_{pr}) \sum_{f}\frac{\nu}{\nu^{2}+(\omega-\omega_{fe(T)}(\boldsymbol{R}_{e}(T)))^{2}} |\mu_{e(T)f}(\boldsymbol{R}_{e}(T))|^{2}\]

Description

This function estimates the Window (window) parameter under the following approximations:

  • Evolutions of electronic coherences in the DW operators are evaluated within the short-time classical Condon approximation.
  • T-evolutions of electronic populations, are replaced by evolutions along trajectories.
  • The quantum thermal distribution in the electronic ground state is substituted by the corresponding phase-space Wigner distribution.
  • The trace over vibrational degrees of freedom is replaced by stochastic sampling of the initial conditions.

The corresponding Window formula (see Ref. [1] formula 60) of the excited-state absorption (ESA) reads:

\[W_{II}^{int}(\omega_{pr},\boldsymbol{R}_{e},\boldsymbol{P}_{e}) = \sum_{f}^{ } E_{pr}^{2}(\omega_{pr}-U_{fe(T)}(\boldsymbol{R}_{e})) \left| (\boldsymbol{\mu}_{e(T)t}(\boldsymbol{R}_{e}) \right|^{2} \]

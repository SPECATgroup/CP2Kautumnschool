WaveMixings._orientational_averaging — Method
_orientational_averaging(tdm::AbstractVector{T},
                        geom_factors::AbstractVector{T}) where {T <: Real}

Computes orientational averaging of a transition dipole moment (x,y,z)

Arguments

  • tdm: transition dipole moment with compoments x, y, and z
  • geom_factors: geometrical factors of the laser pulses

Returns

Averaged transition dipole moment over the random orientations.

Description

This functions computes the orientational averaging of the transition dipole moment over random orientations of molecules in the ensemble. This implementation is the most general, thus it permits many different type of laser pulse configurations. The arrangament of those configurations yield the geometrical factors of the laser pulses, which we compute with the function get_geometrical_factors and pass to this function via the parameter (geom_factors). See get_geometrical_factors for a full description of the geometrical factors and their implementation in WaveMixings.jl (see Ref. [1] formula 135)

\[ \overline{I_{\alpha}^{abcd}} = \frac{1}{30}\left(\textrm{g}_{1}(\boldsymbol{s}) + \textrm{g}_{2}(\boldsymbol{s})+ \textrm{g}_{3}(\boldsymbol{s})\right) \left(I_{\alpha}^{(xxxx)}+I_{\alpha}^{(yyyy)}+I_{\alpha}^{(zzzz)}\right)\]

\[+ \frac{1}{30} \textrm{g}_{1}(\boldsymbol{s}) \left(I_{\alpha}^{(yyxx)}+I_{\alpha}^{(zzxx)}+I_{\alpha}^{(xxyy)}+I_{\alpha}^{(zzyy)} +I_{\alpha}^{(xxzz)}+I_{\alpha}^{(yyzz)}\right)\]

\[+ \frac{1}{30} \textrm{g}_{2}(\boldsymbol{s}) \left(I_{\alpha}^{(yxyx)}+I_{\alpha}^{(zxzx)}+I_{\alpha}^{(xyxy)}+I_{\alpha}^{(zyzy)} +I_{\alpha}^{(xzxz)}+I_{\alpha}^{(yzyz)}\right)\]

\[\frac{1}{30} \textrm{g}_{3}(\boldsymbol{s}) \left(I_{\alpha}^{(yxxy)}+I_{\alpha}^{(zxxz)}+I_{\alpha}^{(xyyx)}+I_{\alpha}^{(zyyz)} +I_{\alpha}^{(xzzx)}+I_{\alpha}^{(yzzy)}\right)\]

WaveMixings.esa_wind_2d! — Method
esa_wind_2d(probe::T, Τ::T, ω_T::AbstractMatrix{Real},
            self::WaveMixing, frame::Integer, dephase::T=0.1)

Calculates the ESA Window (eq. 11 in Xiang JPCL, 11738. 2021) from energies, oscillator strengths, probe energy, frame number, etc. as input. The Window is calculated from the n-th data point of the trajectory. The signal is calculated from the spectrum energy in the frequency domain. For the available methods check the function spectrum_energy_fourier. Use with Excited State Absorption Dynamics.

Arguments

  • WaveMixing: composite containing oscillators, method and energies parameters.
  • probe: a probe pulse energy.
  • Τ: pulse length.
  • ω_T: array of pumped frequencies.
  • frame: frame number in the non-adiabatic trajectory.
  • dephase: dephasing parameter. the default gives 0.1 eV.

Returns

The WaveMixing composite (ESA) is updated with all the important information, namely window_2d. The Doorway signal is a Complex Matrix with n-scanned (pump) collums, and a row.

Description

In 2D spectroscopy, the pump pulse of PP spectroscopy is replaced by a pair of phase-coherent excitation pulses. The first pulse establishes a coherence between the electronic ground state and the bright excited electronic state. The second pulse, which is delayed by the so-called coherence time $\tau$$, converts the coherence into populations of the ground state and the excited state. By monitoring the correlation of two transition frequencies and its evolution with the waiting time, 2D spectroscopy provides dynamical information which is not exposed in one-dimensional (PP) spectroscopies.

The corresponding Window formula (see Ref. [1] formula 11) of the excited-state absorption (ESA) reads:

\[W_{\mathrm{I}}^{2D}(\omega_{t},\boldsymbol{R}_{e(T)}(T),\boldsymbol{P}_{e(T)}(T)) = \frac{E_{4}^{2}(\omega_{t}-\omega_{p})|\mu_{ge(T)}(\boldsymbol{R}_{e(T)}(T))|^{2}}{\nu+ i(U_{e(T)g}(\boldsymbol{R}_{e(T)}(T))-\omega_{t})}\]

Cite

[1] Huand et.al. J. Phys. Chem. Lett. 2021, 12, 11736−11788

See also gsb_wind_2d!, and se_wind_2d!.

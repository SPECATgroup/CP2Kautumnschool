Input data

Now that we know that WaveMixings is inatalled, we can procede to input the most basic data to perform the simulations.

Bellow YOU put all the necesary data for the calculation. For this script, one only needs the name of files with energies and transition dipole moments (TDMs). The user is reponsable for providing the files (energies and TDMs).

These are your files with energies and TDMs. For real calculations you will need 100s of these files, so by default WaveMixings expect them to be in a separate folder, EACH PAIR of files.

input_ener  = "data_hopping/energies.dat"
input_tdms  = "data_hopping/tdm_xyzs.dat"
"data_hopping/tdm_xyzs.dat"

We need pulse duration, pump and probe carrier frequencies. Time delay in femtoseconds

pulse_time = make_pulse_duration(5.0)
206.70687287875498

Probe carrier frequencies in eV. From 2 till 6 eV, 200 points

probe_freq = make_probe_freq(1, 6, 200)
1×200 Matrix{Float64}:
 0.0367493  0.0376727  0.038596  0.0395194  …  0.218649  0.219573  0.220496

Pump carrier frequency, from 3.0 eV

pump_frequ = make_pump_freq(3.0)
0.1102479665273215

You will need to import the energies and TDMs, with the corresponding function of how the data was calculated, i.e GSB, SE, or ESA.
